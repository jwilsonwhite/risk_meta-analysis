# risk_meta-analysis
Predation risk meta-analysis

Code that performs all of the analyses and creates figures for the manuscript:
Peckham N, White JW, Cherry MJ, Haag N, Peacor SD, Sheriff MJ, Smith JA, Kimbro DL. A synthesis of temperature-dependent predator risk effects: trends and knowledge gaps across response type and system. Journal of Animal Ecology, submitted

Code originally authored by Nicole Peckham, updated by Will White. September 2026

Files:

tempmaster6aug2026.xlsx contains the meta-analysis dataset

ch2_metaanalysis_6aug2026.Rmd loads the data, performs all analysis, and creates figures.
